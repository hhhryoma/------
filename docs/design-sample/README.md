# 詳細設計サンプル（受注管理システム・架空）

設計工程向けツール（設計書リーダー、DDL 生成、整合チェックなど）の開発・検証用に作成した、**架空のシステムの詳細設計書一式**です。
日本の SI でよく使われる Excel 方眼紙（セル結合あり）の書き方で作成しています。特定の企業や開発標準の様式を写したものではありません。

設計書どうしの参照（画面項目→テーブル列、メッセージ ID、コード値、遷移先画面）はすべて整合が取れています。
ツールの「正解データ」として使い、誤りを検出するテストでは、このファイルを書き換えたものを使ってください。

## 対象システム

受注担当者が、顧客からの受注を登録・照会・変更・キャンセルする Web 業務アプリ。
登録時に商品の在庫を引き当て、毎日 18:00 に受付状態の受注を物流システムへ出荷指示として送信する。

```
受注一覧（SCR001）──新規登録──▶ 受注登録（SCR002）
   ▲  │                              │登録
   │  └──受注番号リンク──▶ 受注詳細（SCR003）◀┘
   └──────────── 戻る ──────────────┘
```

## ファイル構成

| ファイル | 内容 | 主なシート |
| --- | --- | --- |
| `DD01_画面一覧.xlsx` | 画面の一覧と画面遷移 | 画面一覧、画面遷移 |
| `DD02_画面設計書_SCR001_受注一覧.xlsx` | 検索・一覧画面 | 画面概要、画面レイアウト、画面項目定義、イベント定義、表示制御 |
| `DD02_画面設計書_SCR002_受注登録.xlsx` | 登録画面（明細あり） | 同上 |
| `DD02_画面設計書_SCR003_受注詳細.xlsx` | 照会・更新・キャンセル画面 | 同上 |
| `DD03_テーブル定義書.xlsx` | 4 テーブル（顧客マスタ、商品マスタ、受注、受注明細） | テーブル一覧、テーブルごとのシート |
| `DD04_コード定義書.xlsx` | 5 コード区分（受注ステータスなど） | コード一覧 |
| `DD05_メッセージ一覧.xlsx` | 16 メッセージ | メッセージ一覧 |
| `DD06_IF定義書_IF001_出荷指示データ.xlsx` | 物流システムへの CSV ファイル連携 | IF概要、レコード定義 |

どのブックも先頭に「表紙」「改訂履歴」シートがあります。テーブル定義書だけは版数 1.1 で、改訂履歴に 2 版目の変更（配送時間帯の追加）が記載されています。

## シートのレイアウト

ツールで読み取るときの目安です。列幅をそろえた方眼（A〜BF の 58 列）に、セルを結合して書いています。
**結合セルの値は、結合範囲の左上セルに入っています。**

### 共通ヘッダ（表紙・改訂履歴以外の全シート）

| 位置 | 内容 |
| --- | --- |
| A1:N2 | 文書名（画面設計書、テーブル定義書 など） |
| O1 / S1 | 「システム名」／ 値 |
| O2 / S2 | 「画面ID」「テーブルID」「IF ID」または「サブシステム」／ 値 |
| Y2 / AC2 | 「画面名」「テーブル名」「IF名」／ 値（ID と名前を持つシートのみ） |
| AI1 / AM1、AU1 / AY1 | 「作成者」「作成日」／ 値 |
| AI2 / AM2、AU2 / AY2 | 「更新者」「更新日」／ 値 |

### 表（項目定義・カラム定義など）

- 「■ 見出し」の行の次の行が、表の見出し行です（淡い青の塗り）
- 見出し行の次の行から、空行が出るまでがデータ行です
- 列の位置は見出しの文字で特定してください（列は結合されていて、見出しと値は同じ開始列にあります）

| シート | 表の見出し |
| --- | --- |
| 画面項目定義 | No / 項目名 / 項目ID / 区分 / 入出力 / 型 / 桁数 / 必須 / 初期値 / 入力チェック / 対応項目 / 備考 |
| イベント定義 | イベントID / イベント名 / トリガー / 処理概要 / 使用テーブル / メッセージ / 遷移先 |
| 表示制御（状態） | No / 状態 / 条件 / イベント（その状態になるイベント） |
| 表示制御（項目の表示制御） | No / 項目名 / 項目ID / 状態ごとの列（○:表示 △:非活性 ×:非表示 表示のみ） / 備考 |
| テーブルごとのシート（カラム定義） | No / 論理名 / 物理名 / データ型 / 桁数 / 小数 / PK / 必須 / デフォルト / 外部キー参照先 / 備考 |
| テーブルごとのシート（インデックス定義） | No / インデックス名 / カラム / ユニーク / 備考 |
| コード一覧 | コード区分ID / コード区分名 / コード値 / 表示名 / 表示順 / 備考 |
| メッセージ一覧 | メッセージID / 種別 / メッセージ / パラメータ |
| レコード定義 | No / 項目名 / 項目ID / 属性 / 桁数 / 必須 / 編集形式 / 設定元 / 備考 |
| 画面遷移 | No / 遷移元画面ID / 遷移元画面名 / イベント / 遷移先画面ID / 遷移先画面名 / 引き渡し項目 / 備考 |

## 設計書どうしの参照

| 参照元 | 書き方 | 参照先 |
| --- | --- | --- |
| 画面項目定義「対応項目」、レコード定義「設定元」 | `テーブルID.カラム物理名`（例 `T_ORDER.ORDER_NO`） | テーブル定義書 |
| 画面項目定義「桁数」 | 文字・数値の項目は、対応するカラムの桁数と一致 | テーブル定義書 |
| イベント定義「使用テーブル」 | `テーブルID(CRUD)` をカンマ区切り（例 `M_PRODUCT(R,U)`） | テーブル定義書 |
| イベント定義「メッセージ」、入力チェック欄の（E0001） | メッセージ ID | メッセージ一覧 |
| 備考の「コード定義 C001」 | コード区分 ID | コード定義書 |
| イベント定義「遷移先」 | 画面 ID | 画面一覧（画面遷移シートと一致） |
| カラム定義「外部キー参照先」 | `テーブルID.カラム物理名` | テーブル定義書 |
| 表示制御「項目名」「項目ID」と状態の列 | 画面項目定義のすべての項目（隠し項目は ×）。状態の列は状態の表と同じ名前 | 同じ画面設計書の画面項目定義 |
| 表示制御（状態）「イベント」 | イベント ID を「、」区切り | 同じ画面設計書のイベント定義 |

これらの参照が合っているかは [Test-DesignConsistency.ps1](../../tools/README.md#test-designconsistencyps1) で確かめられます（表示制御は [表示制御](../../tools/README.md#表示制御画面項目の表示非活性非表示)）。

各画面の表示制御の状態:

| 画面 | 状態（その状態になるイベント） | 状態で変わる項目 |
| --- | --- | --- |
| SCR001 受注一覧 | 初期表示（EV01、EV03）・検索後（EV02、EV06）・該当なし（EV02） | 検索結果件数・受注一覧と一覧の項目は、初期表示で非表示。一覧は該当なしでも非表示 |
| SCR002 受注登録 | 入力中（EV01、EV05）・明細20行（EV05） | 行追加は、明細20行で非活性 |
| SCR003 受注詳細 | 受付（EV01、EV02）・出荷指示済（EV01）・キャンセル（EV01、EV03） | 希望納品日・配送時間帯・備考は受付のときだけ変更でき、更新・キャンセルボタンは受付のときだけ表示 |

## データ型

テーブル定義書のデータ型は標準 SQL の型（`CHAR` `VARCHAR` `NUMERIC` `INTEGER` `DATE` `TIMESTAMP`）で書いています。
DDL を生成するときに、対象 DB の型（Oracle の `VARCHAR2`・`NUMBER` など）へ変換する想定です（[Export-TableDdl.ps1](../../tools/README.md#export-tableddlps1) で作れます）。

## 再生成

内容はすべて `tools/design_data.py` に定義しています。編集したら次のコマンドで xlsx を作り直してください（openpyxl が必要）。

```bash
cd tools && python make_samples.py
```
