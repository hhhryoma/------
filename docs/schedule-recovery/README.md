# スケジュール遅延リカバリ計画テンプレート

顧客（発注元）へ、スケジュール遅延の状況・原因・回復計画をご報告するための汎用Excelテンプレートです。
具体的な案件情報は未記入の雛形で、各表の1行目に「記入例」（淡橙・斜体）を入れてあります。

**ファイル**: `スケジュール遅延リカバリ計画_テンプレート.xlsx`

## シート構成

| シート | 用途 |
| --- | --- |
| 00_記入ガイド | 作成手順（STEP1〜8）、セルの色の意味、社外提出時の注意、提出前チェックリスト |
| 01_サマリ | 顧客提出用の1枚サマリ。数値は他シートから自動参照、文章欄のみ記入 |
| 02_遅延状況 | 遅延タスク一覧。当初日程と実績／見込日程から遅延日数を自動計算 |
| 03_原因分析 | 事象→直接原因→なぜなぜ→真因→再発防止策 |
| 04_リカバリ施策 | 施策一覧（短縮日数・追加コスト・採否）＋案A/B/C比較表 |
| 05_新スケジュール | 変更後マイルストーンと最終納品日、前提条件 |
| 06_影響・リスク | 遅延の影響評価＋リカバリ計画自体のリスク（スコア自動計算） |
| 07_アクション管理 | 誰が・何を・いつまでに。期限超過を自動判定 |
| 08_週次モニタリング | 週次の計画／実績、累計・達成率を自動計算 |

## 記入の順番

02（状況把握）→ 03（原因）→ 04（施策）→ 05（新日程）→ 06（影響・リスク）→ 07（アクション）→ 01（サマリ）→ 08（以後の運用）

サマリを最後に書くことで、シート間で数字が食い違いません。

## セルの色

| 色 | 意味 |
| --- | --- |
| 淡黄＋青文字 | 記入セル。ここだけ埋めれば資料が完成します |
| 淡灰＋黒文字 | 自動計算セル。数式が入っているため上書きしないでください |
| 淡橙＋斜体 | 記入例。**提出前に必ず削除**してください |
| 濃紺＋白文字 | 表の見出し |

## 主な自動計算

- 遅延日数 = 実績／見込終了日 − 当初終了日（02、05）
- 採用施策の短縮見込日数・追加コスト合計（04、`SUMIF` で採否＝「採用」のみ集計）
- リスクスコア = 発生確率 × 影響度（06、換算表 低1／中2／高3）
- 期限超過件数 = 未完了かつ期限が本日より前（07）
- 累計計画／累計実績／達成率（08）

01_サマリの数値は 02・04・05 を参照しているため、元シートを更新すれば自動で反映されます。

## 社外提出時の注意

- 「03_原因分析」の *責任区分* は社内整理用の項目です。契約・請求に直結するため、提出可否は営業／契約担当と事前に確認してください。
- 新納期は必ず前提条件つきで提示し、前提が崩れた場合の扱いも明記してください。
- 未確定の数値は空欄にせず「調整中（〇月〇日回答予定）」と記載し、次回報告日をセットで示してください。
