# 自作のエージェント・ハーネス

Claude にツールを持たせて、タスクが終わるまで自分で動かす「ハーネス」を、少しずつ作っていく練習用のフォルダです。

## しくみ

```
ユーザーの依頼
   ↓
┌→ ① モデルに「会話の履歴」と「使えるツールの一覧」を送る
│     ↓
│  ② 返事を見る
│     ├ ツールを使いたい（stop_reason が tool_use）→ ③へ
│     └ それ以外（end_turn など）→ 終わり
│     ↓
│  ③ ハーネスがツールを実際に実行する
│     ↓
└─ ④ 実行結果を履歴に足して ① に戻る
```

| ファイル | 中身 |
|---|---|
| `harness.py` | ハーネスの本体（① ツールの定義、② ツールの実行、③ 権限の確認、④ ループ） |
| `test_harness.py` | API を呼ばずにループの動きを確かめるテスト |

## 動かす

Python 3.10 以上と、Anthropic の API キーが必要です。API キーは [Claude Console](https://platform.claude.com/) で作ります。

**Windows（PowerShell）**

```powershell
cd agent-harness
py -m pip install -r requirements.txt
$env:ANTHROPIC_API_KEY = "sk-ant-..."
py harness.py このフォルダにあるファイルを数えて
```

**Mac / Linux**

```bash
cd agent-harness
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
python harness.py このフォルダにあるファイルを数えて
```

コマンドを実行する前に `実行してよいですか? [y/N]` と聞かれます。`y` を入れたときだけ実行します。

## テスト

API キーはいりません。決めておいた返事を返す「偽のクライアント」でループを動かします。

```
python -m unittest test_harness.py -v
```

## これから作るもの

- [x] **ステップ 1**: 最小のループ（ファイルを読む、コマンドを実行する、実行前に確認する、回数の上限）
- [ ] **ステップ 2**: ファイルを書く・直すツール（直す前に差分を見せて確認する）
- [ ] **ステップ 3**: 返事を少しずつ表示する（ストリーミング）
- [ ] **ステップ 4**: 長い会話の管理（古いツールの結果を消す、要約する）
- [ ] **ステップ 5**: 料金を抑える（プロンプトのキャッシュ）と、記録を残す（ログ）

## 気をつけること

- **モデルの返事は手を加えずに履歴に足す。** 文字だけ取り出したり、前の発言を書き換えたりすると、エラーや性能の低下の原因になります。
- **同時に頼まれたツールの結果は、1 つのメッセージにまとめて返す。**
- **ツールのエラーも結果として返す**（`is_error: True`）。モデルはそれを見て自分で直そうとします。
- **コマンドを実行するツールは強力です。** 大事なファイルがない場所で試してください。
